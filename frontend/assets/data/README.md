# ข้อมูลที่อยู่ประเทศไทยสำหรับหน้ายืนยันตัวตน

`thai_addresses.json` เก็บ 77 จังหวัด 928 อำเภอ/เขต และ 7,436 ตำบล/แขวง
พร้อมรหัสไปรษณีย์ในแอป จึงเลือกที่อยู่ได้โดยไม่ต้องเรียกบริการภายนอก

- ชื่อและลำดับชั้นพื้นที่ รวมถึงรหัสไปรษณีย์หลัก: [thailand-geography-json](https://github.com/thailand-geography-data/thailand-geography-json/tree/b8b3fb91c7df1129ff5b43cb46f7fcffadd2156b) (MIT)
- รหัสไปรษณีย์ทางเลือก: [jquery.Thailand.js](https://github.com/earthchie/jquery.Thailand.js/tree/2f2737e560acc88e6bf1144e8fad3355a72d977d) (WTFPL)

เพิ่มรหัสทางเลือกเฉพาะแถวที่ชื่อจังหวัด อำเภอ/เขต และตำบล/แขวงตรงกันครบ
เก็บรหัสหลักจากชุดพื้นที่ไว้เป็นตัวแรก และลบรหัสซ้ำ พื้นที่ที่มีหลายรหัสมี 88 แห่ง
ข้อมูลเป็น snapshot ของชุมชน ไม่ใช่บริการข้อมูลสดของไปรษณีย์ไทย ผู้ใช้แก้ไขรหัสได้
ดูข้อความลิขสิทธิ์ต้นฉบับใน `THIRD_PARTY_LICENSES.txt`

สร้างไฟล์และลิขสิทธิ์ซ้ำจากโฟลเดอร์ `frontend/` ด้วย `python tool/update_thai_address_data.py`
หากเปลี่ยน commit ต้นทาง ให้ตรวจจำนวนพื้นที่ การย้ายเขต/เปลี่ยนชื่อ และรหัสทางเลือกก่อนอัปเดต
